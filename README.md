# Cat Inspire

A VS Code extension that was inspired by [Written Kitten](https://writtenkitten.co/). It retrieves cat pictures from
[The Cat API](https://thecatapi.com/).

## Commands

`catInspire.start` : Opens up a new panel where pictures of cats will be displayed.

## Configuration

`catInspire.validLanguages` : Which languages should the extension count words for. Defaults to markdown and plaintext.

`catInspire.wordsTillNextPicture` : How many words need to be typed until the picture changes. Defaults to `100`.

`catInspire.catApiKey` : By default the API allows anyone without a key to retrieve ten pictures for free. This could change in the
future.
